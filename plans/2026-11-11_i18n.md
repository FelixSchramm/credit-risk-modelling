# Plan: bilingual app (issue #41)

1. `src/locales/en.toml`, `de.toml`: same tables (`app`, `nav`, `common`, `home`).
2. `src/i18n.py` (no Streamlit): `translate`, `fmt_number`, `fmt_percent`,
   `SEPARATORS`. Missing key or language raises `KeyError`, no fallback.
3. `app/ui.py`: `init_language`, `current_lang`, `t`, `num`, `pct`; `show_chart`
   passes the separators; error message of `get_bundle` translated; docstring
   states the fixed-`key=` rule.
4. `streamlit_app.py`: language from URL on first run, `st.radio` switcher
   (key `lang`, cannot be deselected) at the top of the sidebar, `lang` written
   back to the query parameters every run. The built-in navigation is drawn
   above sidebar content, so it is hidden and the menu is drawn below the
   switcher with `st.page_link` (titles from `nav.<key>`).
5. `app/views/home.py` uses `t()`.
6. Tests: `tests/test_i18n.py`; smoke test in both languages and a switch test.
7. README layout and one sentence, HANDOVER.
