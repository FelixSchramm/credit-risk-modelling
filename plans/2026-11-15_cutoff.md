# Plan: cut-off and expected loss page (issue #35)

1. `src/scoring.py`: `cutoff_table(y_true, proba, thresholds, loss_share,
   margin_share, loan_amount)`, vectorised (scores sorted once, cumulative sums
   of the labels, `searchsorted` per threshold, no Python loop). One row per
   threshold: accepted, rejected, caught and missed defaults, rejected good
   customers, approval rate, default rate in the accepted part, precision,
   recall, net result. A loan is rejected if its score is strictly above the
   threshold (as `charged_off_metrics`). Tests: counts against a brute-force
   count, precision and recall against `charged_off_metrics`, net result by
   hand, edge thresholds.
2. Net-result model (illustration, not a portfolio calculation): net result =
   `margin_share * loan_amount` per accepted good loan minus
   `loss_share * loan_amount` per accepted default. Rejected loans earn and
   lose nothing, so the optimum is the same as minimising the loss of missed
   defaults plus the foregone margin. The bundle has no per-loan amount for the
   test set, so one amount is used: the median `loan_amnt` of `input_spec`
   (assumption, stated on the page). LGD and EAD are not modelled; the page
   says so.
3. Glossary: all eight required keys exist; add none unless a gap shows up.
4. `app/views/cutoff.py`, registered in `PAGES` after `performance`;
   `nav.cutoff`, `nav_desc.cutoff`, `[cutoff]` in both locale files. Inputs
   with fixed keys: model radio, threshold, loss share, margin share (the
   sliders are `select_slider` so the numbers follow the language through
   `format_func`). Sections: notice, inputs, metrics with tooltips, net-result
   curve with the optimum marked by marker and label (single axis,
   `show_chart`), a short interpretation.
5. Tests: smoke test per language, slider changes the metrics, inputs survive a
   language switch, optimum marker present.
6. `st.page_link` from the performance page note to the new page.
7. Real bundle: numbers at three thresholds, optimum, consistency checks;
   headless start; screenshots; HANDOVER.
